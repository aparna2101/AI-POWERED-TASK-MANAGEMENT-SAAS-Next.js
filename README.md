# TaskAura — AI-Powered Task Management SaaS

Next-generation AI-powered task management workspace built with Next.js, Three.js, TailwindCSS, and Web Audio API.

## 🚀 Features
- 🤖 **Interactive AI Copilot**: Real-time project automation, task generation, and conversational workflow assistance.
- 🌐 **Interactive 3D Visualizations**: Real-time Three.js particle nexus, cyber vaults, neural synapse canvases, and knowledge matrices.
- 📋 **Complete Workspace App**: Kanban boards, Calendar scheduling, Analytics charts, Team member directory, and Project tracking.
- 🔊 **Web Audio Synthesizer**: Low-latency, tactile interactive click, hover, and completion sound engine.
- 🎙️ **Neural Voice Engine**: Voice-activated AI greetings and assistance.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile views.

## 🛠️ Tech Stack
- **Framework**: Next.js 14+ (App Router)
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js
- **Icons**: Lucide React
- **Audio**: Web Audio API & Web Speech Synthesis

## 💻 Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
